# Medical Image Analysis Internship

This repository contains the work completed during my summer internship, focused on **medical image analysis, machine learning, deep learning, and computer vision**.

## 📌 Overview

The project involved experimenting with multiple medical imaging datasets, comparing pretrained CNN architectures, evaluating their performance, and optimizing a selected model for **Chest X-Ray Pneumonia classification**.

## 🧠 Work Covered

- Worked with **5 medical imaging datasets**
- Adapted the pipeline to different dataset structures and formats
- Compared multiple pretrained **CNN architectures**
- Performed **deep feature extraction**
- Evaluated models using:
  - Accuracy
  - Precision
  - Recall
  - F1 Score
  - Cohen's Kappa
- Optimized **InceptionResNetV2** using transfer learning and fine-tuning
- Worked with **TensorFlow / Keras**
- Debugged practical **GPU, RAM, WSL, and memory-management** issues
- Generated architecture diagrams, comparison tables, and research documentation

## 📂 Repository Contents

### `notebooks/`
Jupyter notebooks containing the dataset processing, model experimentation, evaluation, and optimization work.

### `research-paper/`
LaTeX source files for the research-paper documentation.

### `figures/`
Architecture diagrams, graphs, and other visual results generated during the experiments.

## 📊 Datasets

The experiments covered:

1. Diabetic Retinopathy Detection
2. Chest X-Ray Pneumonia
3. HAM10000
4. Kvasir V2
5. PatchCamelyon (PCam)

## 🔬 Final Optimization

After the comparative experiments, **Chest X-Ray Pneumonia** was selected for further optimization. The work focused on fine-tuning InceptionResNetV2, extracting compact feature representations using Global Average Pooling, and evaluating the resulting features with both neural-network and classical ML classifiers.

## 📄 Documentation

The repository includes the notebooks, experiment results, architecture diagrams, and LaTeX source files used to document the work in a research-paper format.
